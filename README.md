This project is designed to identify nosy individuals, so that they cannot easily gain access to people's privacy. If our camera is ever turned on, the system will be able to detect them. You need Windows and a webcam; you must extract the entire folder from the ZIP file and run FoozoolDetection.exe from within that same folder.


you can use this command for install it:
pip install -r requirements.txt
python FoozoolYab.py
